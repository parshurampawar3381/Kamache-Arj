विकसकाचे नाव

हे नाव ॲपच्या सर्वात खाली आणि फॉर्मच्या प्रत्येक पानाच्या उजव्या खालच्या कोपऱ्यात लहान अक्षरात येते.

Admin PIN बदला

वरील GitHub माहिती (विशेषतः token) भरलेली असावी. नवीन PIN सर्व वापरकर्त्यांसाठी Admin उघडण्यास लागू होईल.

अतिरिक्त माहितीचे रकाने (काम निवडून)

जिल्हा, तालुका, ग्रामपंचायत, लाभार्थी नाव, प्रवर्ग, जॉबकार्ड, आधार, बँक खाते, IFSC, बँकेचे नाव, ठराव क्र./दिनांक आणि गट/खाते/मिळकत नं. हे रकाने सर्व फॉर्मसाठी कायम असतात. एखाद्या फॉर्मला आणखी माहिती लागत असेल (उदा. कामाचा सांकेतांक) तर येथे रकाना जोडा. हवे तेवढे रकाने जोडता येतात.
